# Final Physical Design Outputs

This folder contains the final outputs generated by the OpenROAD physical design flow for my **Password Based Digital Door Lock** using the SKY130HD platform.
I have pasted first 70 lines of the files only.

## File Descriptions

- **`6_final.odb`** – The final OpenROAD database, containing the physical design information. The generated file size is approximately 2.5 MB.
- **`6_final.def`** – Describes the physical layout, including the die area, placement rows, routing tracks, vias, and standard-cell placement.
- **`6_final.v`** – Contains the final gate-level Verilog netlist, including the design's input/output ports and mapped logic connections.
- **`6_final.sdc`** – Defines the timing constraints, including the clock period of 20 ns, input delay, and output delays.
- **`6_final.spef`** – Contains extracted parasitic information, including resistance and capacitance data used for post-layout timing analysis.

## Purpose

These files represent the final physical implementation of the password of digital lock and provide the design data needed for further timing analysis and verification.
