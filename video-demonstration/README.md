# 🔐 Password-Based Digital Door Lock System

## 📌 About the Project

This project implements a secure digital door lock using password authentication.

## 🎯 Objective

To provide secure and convenient access control for doors.

## ⚙️ Working

Users enter a password through a keypad to unlock the door.

## 🔒 Security

Only users who enter the correct password can gain access.

## 🚪 Applications

Homes, offices, laboratories, and restricted areas.
